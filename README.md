# 中国旅行足迹地图

一个纯前端、单文件、离线可用的中国旅行足迹地图。

## 功能

- 按具体城市或地区逐个点亮、取消，不提供一键点亮全省
- 覆盖 370 个可独立记录的城市与地区，包括仙桃、天门、神农架及新疆自治区直辖县级市等
- 自动统计已点亮地点数量与涉及省份数量
- 使用浏览器本地存储自动保存
- 导出、导入本地 JSON 足迹文件
- 生成 PNG 旅行足迹海报
- 地图边界数据内嵌，不加载任何远程资源

## 使用

直接打开仓库中的 `index.html`，或下载 `中国旅行足迹地图.html` 后双击运行。

边界数据整理自 DataV.GeoAtlas，仅用于个人旅行足迹记录，不作为行政边界依据。
